# ADR-0012: التخزين الخارجي للأرشيف والنسخ الاحتياطي (ObjectStorage)

- **الحالة:** مقبول ✅ (مُنفَّذ)
- **التاريخ:** 6 أكتوبر 2026

## السياق
حزم الأرشيف (Excel/PDF/JSON + manifest) وقواعد النسخ الاحتياطي (ملفات مشفّرة) يمكن أن تكبر وتُعالج بواسطة منصات S3 (MinIO محلياً). يجب ألا تُربط الخدمات بمسار نظام الملفات المحلي.

## القرار
- **واجهة `ObjectStorage`** بدرايفرين: `local` (مسار نظام الملفات) و`s3` (امتثال AWS S3) — تُختار بالإعداد (`STORAGE_DRIVER`).
- الأرشيفات/النسخ الاحتياطية تُخزَّن عبر هذه الواجهة؛ الـmanifest يتضمّن أسم ملفاتها + sha256.
- `docker-compose.yml` يضيف خدمة **MinIO** (فورك «سايلو»؛ الصور الأصلية حُذفت من Docker Hub + quay 2026 — استُخدم صورة متاحة).

## العواقب
- ✅ تحرّر الخدمات من مسار محلي؛ قابلية النقل إلى S3 حقيقي.
- ✅ تحقق النسخ الاحتياطية (checksum + decrypt + verify endpoint).
- ⚠️ يجب ضبط بيانات اعتماد S3 ودلو bucket لكل بيئة.
