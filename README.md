# بيان — Bayan ERP

نظام متكامل لشركة تبيع الحديد والبويات (جملة وقطاعي): الأصناف والوحدات المتعددة،
الأسعار، المشتريات، المخازن والجرد، المرتجعات، العملاء والمناديب، التتبع الجغرافي،
والترحيل الدوري للبيانات.

> المستند التصميمي المرجعي: `docs/bayan-design.md` — خطة التنفيذ: `docs/PLAN.md`
> دليل النشر للإنتاج: `docs/DEPLOYMENT.md`

## المكونات

| المسار            | التقنية                       | الوصف                                                       |
| ----------------- | ----------------------------- | ----------------------------------------------------------- |
| `apps/api`        | NestJS + PostgreSQL (PostGIS) | الخادم والـ API (Swagger على `/api/docs`)                   |
| `apps/web`        | Next.js + Tailwind (RTL)      | لوحة التحكم                                                 |
| `apps/mobile`     | Flutter + Drift               | تطبيق المناديب (المرحلة 4)                                  |
| `packages/shared` | TypeScript                    | محرك الحسابات والترقيم المشترك (مصدر الحقيقة للمنطق المالي) |

## التشغيل

```bash
pnpm install          # تثبيت الاعتمادات
pnpm dev              # تشغيل التطوير (turbo)
pnpm build            # بناء الكل
pnpm test             # الاختبارات
pnpm lint && pnpm typecheck

docker compose up -d  # PostgreSQL + Redis + MinIO
cp .env.example .env  # متغيرات البيئة
```

- API: http://localhost:3000/api/health — مستندات Swagger: `/api/docs`
- Web: http://localhost:3000 (أو 3001 حسب المنفذ المتاح)

## قواعد أساسية

- كل الواجهات **عربية RTL**، والعملة جنيه مصري.
- المستند يسمى **«بيان أسعار»** (BP-)، والتوريد «بيان توريد» (PR-)، والمرتجع «بيان مرتجع» (RT-).
- حسابات الخصومات والوحدات والترقيم تُكتب أولاً في `packages/shared` مع اختبارات،
  ثم تُستخدم من الـ API والويب؛ والموبايل يطابقها عبر اختبارات ذهبية (Dart port).
- `period_id` إلزامي على كل جداول الحركات (أساس عملية الترحيل لاحقاً).
